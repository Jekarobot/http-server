# HTTP Server

🚀 Простой HTTP-сервер для обработки запросов и раздачи статического контента.

## 📋 Описание

Проект представляет собой легковесный HTTP-сервер, предназначенный для быстрого развертывания и обработки входящих запросов. Идеально подходит для прототипирования, тестирования или в качестве основы для более сложных веб-приложений.

## 🛠 Технологический стек

- **Язык:** JavaScript (Node.js)
- **Среда выполнения:** Node.js
- **Платформа:** Heroku / Railway (через Procfile и railway.json)

## 📦 Установка и запуск

### Предварительные требования

- Установленный Node.js (версия 14 или выше)
- npm (менеджер пакетов)

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/http-server.git

# Перейдите в директорию проекта
cd http-server

# Установите зависимости
npm install
```

### Запуск

```bash
# Запуск сервера
npm start
```

Сервер будет доступен по адресу `http://localhost:3000` (или порту, указанному в переменной окружения `PORT`).

## 💻 Примеры использования

### Базовый запрос

```bash
# Отправка GET-запроса
curl http://localhost:3000

# Ответ сервера
Hello World!
```

### Использование с переменными окружения

```bash
# Запуск на определенном порту
PORT=8080 npm start
```
